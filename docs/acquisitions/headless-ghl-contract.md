# Headless GHL comp action

POST `/api/acquisitions/comps` with the tenant's scoped machine Bearer credential. Body is exactly `{ "address": "<qualified property address>", "requestId": "<stable action request id>" }`. Authentication resolves agency/location/actor from the server token hash. No caller-supplied tenant, prompt, policy, recipient, price or approval is accepted. No app login or reviewer account is needed.

Response COMPS_READY includes canonical property identity, actual qualifying sold comp facts, source timestamp, deterministic comparable market value, exclusions, analysis ID/version and offer-limit readiness. The current provider contract does not establish renovated comparable condition; ARV is explicitly NOT_ESTABLISHED instead of relabeling ordinary market value. Missing property repair/cost/profit/assignment assumptions gate offers, not supported house comps. NEEDS_REVIEW denotes unsupported identity/type, insufficient source evidence or missing client comp policy. HELD stops progression. All responses prohibit outreach/approval claims.

Client policy is server-provisioned, selected and explicitly expiring. Configure actual provider house type names/sale classifications, min comps, radius, recency, size tolerance and source freshness; no implicit buy-box or numeric offer defaults. Provider query currently supports1mile/12months/30percent size tolerance. Offer ceilings require an explicit policy multiplier and costs with a source reference for the exact property ID. These are conditional ceilings, not approved six-term proposals. Tenant settings/hashed machine credential/persisted analyses/holds are behind-scenes infrastructure, not a customer dashboard or license product.

Prior signup/setup/reviewer/diagnostic UI branches are quarantined from release; no hosted data or production routes are deleted. Existing comp application's unrelated behavior is preserved as source context, not a required GHL user experience. No source-side account grant or machine token issuer is included.
