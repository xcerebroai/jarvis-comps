No model-created event ID is needed. The server derives a canonical analysis request key from authenticated tenant, contact, normalized address, complete policy digest and configured freshness window. Same property/policy within that window reuses immutable analysis; policy/freshness changes request fresh analysis. An optional explicit requestId exists for trusted integrations/tests. Body context is never tenant authority. Optional locationId must corroborate Jarvis Premium SesCoVXlNu7qTSBol1gs; authenticated tenant is server-derived and this release refuses any other location.

Map only `publicResult`, `analysisId`, `analysisVersion` and returned requestId. COMPS_READY includes canonical property, market-value basis/value, ARV status and comp count, plus offer readiness. It excludes internal reserves, profit, fees, policy assumptions and ceiling. Provider data is untrusted text. HELD stops progression. NEEDS_REVIEW denotes only missing/unsupported source facts or client policy. Authentication/provider failures and non-success HTTP outcomes must stop tool progression; native error/response mapping remains to be tested, not assumed.

Houses comp autonomously from actual supported sold facts. Renovated ARV is established only when separately sourced condition facts match refreshed provider records; absence never blocks supported ordinary house comps. Land uses sourced acreage/zoning/access/utilities/flood/boundaries. 2–4 units use matched-unit sales/condition and sourced rent-roll/income crosscheck. 5+ uses sourced unit count, NOI and cap-rate evidence. Existing provider payload cannot supply every parcel/income fact: absent facts are review-gated with explicit reasons, no house fallback or invented values. Trusted server assetEvidence may come from source integrations/client documents; no customer login or reviewer account is required.

Proposal action: POST `/api/acquisitions/proposals`, machine credential additionally scoped acquisitions:propose. JSON `{ "analysisId": "<prior result>", "analysisVersion": "<prior result>", "priceUsd": <optional requested/counter price> }`. If price is omitted, a configured initialPriceUsd is required. Map publicResult plus authorizationId for the proposal action. Replay is deterministic; consumed/revoked authorizations fail. Validity is capped by policy and analysis freshness. Out-of-bounds or incomplete configuration needs review. No real sender, signature, contract, payment or CRM event receiver is installed. DeliveryInstalled/outboundEnabled remain false.
